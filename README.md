# Генератор экзаменационных билетов на Go

Консольная программа спрашивает фамилию и имя студента, выдаёт случайный номер билета от 1 до 20, показывает соответствующий вопрос по предмету **Proiectarea Sistemelor Informaționale** и сразу добавляет запись в `journal.xlsx`. При следующем запуске записи продолжаются с новой строки.

## Запуск

Нужен Go 1.22 или новее. В каталоге проекта:

```bash
go run .
```

По умолчанию журнал создаётся рядом с программой. Путь можно изменить:

```bash
go run . -file ./journal.xlsx
```

В терминале нажмите `ESC`, чтобы выйти. Пустые имя и фамилия не принимаются, пробелы по краям удаляются. После ввода студента программа сохраняет билет и ждёт следующего. Если Excel удерживает журнал открытым, программа предлагает закрыть файл и нажать Enter для повторной записи того же студента.

Банк вопросов в [questions.go](questions.go) составлен для **Proiectarea Sistemelor Informaționale**. Номер билета всегда соответствует одному и тому же вопросу; порядок вопросов нельзя менять после начала заполнения журнала. Вопросы написаны для этого проекта на основе тем [учебного материала UTM](https://repository.utm.md/handle/5014/15231), они не являются официальными экзаменационными билетами конкретного преподавателя.

Приложение рассчитано на терминал macOS или Linux. При запуске с перенаправленным вводом строки читаются обычным способом, поэтому для `ESC` может потребоваться Enter.

## Формат журнала

| A | B | C | D |
| --- | --- | --- | --- |
| Last name | First name | Номер билета | Дата и время |

Файл не добавляется в Git, поскольку содержит персональные данные студентов. Запись сначала создаётся во временном XLSX-файле и затем заменяет журнал. Это сохраняет ранее записанные строки при сбое во время обновления.

## Проверка

```bash
go test ./...
go vet ./...
```

Тесты проверяют создание файла, повторное дописывание, сохранность предыдущей строки, экранирование символов в именах, отказ при Excel-блокировке, пустой ввод и заполненность банка вопросов. GitHub Actions запускает их при каждом push и pull request.
