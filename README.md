# Генератор экзаменационных билетов на Go

## Лабораторная работа 2 — графический интерфейс

Приложение [cmd/lab2](cmd/lab2/main.go) продолжает Лаб 1 для предмета **Proiectarea Sistemelor Informaționale**. Выберите группу, затем студента и нажмите «Сгенерировать билет». Появятся номер и три вопроса; результат сразу запишется в `results.xlsx`. Клавиша ESC закрывает окно билета и возвращает к выбору студента.

В репозитории лежат **демонстрационные** [students.xlsx](students.xlsx) и [tickets.docx](tickets.docx). Фамилии вымышлены, а вопросы составлены для демонстрации и не являются официальными билетами преподавателя. Можно заменить оба файла своими, сохранив имена файлов и формат:

- `students.xlsx`: каждый лист — отдельная группа; строка 1 — заголовки, далее фамилия в A и имя в B.
- `tickets.docx`: заголовок `Билет N`, ниже три строки вида `1. Вопрос`, `2. Вопрос`, `3. Вопрос`.
- `results.xlsx`: создаётся рядом с приложением; содержит группу, фамилию, имя, номер билета, дату и время, признак повтора.

Если студент из той же группы уже получал билет, программа берёт номер из **первой** его записи, но добавляет новую строку с признаком `да`. Для нового студента выбирается один из корректно прочитанных билетов и записывается `нет`. Неполные блоки билетов пропускаются; при отсутствии доступных билетов и при ошибке входных файлов кнопка генерации недоступна. Если Excel удерживает `results.xlsx`, приложение предлагает закрыть файл и повторить сохранение того же результата.

### Windows без установки Go

На странице [Actions](https://github.com/yr3kdvdv/exam-ticket-generator-go/actions) откройте успешную проверку ветки `lab2-ui-tickets` и скачайте артефакт `lab2-windows-amd64`. Распакуйте весь архив в одну папку и запустите двойным щелчком `ticket-generator-gui.exe`. Файлы `students.xlsx` и `tickets.docx` должны остаться рядом с `.exe`; готовый `results.xlsx` появится там же. На компьютере пользователя Go устанавливать не нужно.

Для разработки из исходников нужен Go 1.26+, C-компилятор и системные библиотеки Fyne. Из корня репозитория:

```bash
go run ./cmd/lab2
```

При запуске из другого каталога приложение ищет входные файлы рядом с `.exe`. `results.xlsx` не добавляется в Git. При проверке демонстрационной работы тестовое сохранение выполняется во временном каталоге, чтобы не смешивать его с личными результатами.

## Лабораторная работа 1 — консольная версия

Консольная программа спрашивает фамилию и имя студента, выдаёт случайный номер билета от 1 до 20, показывает соответствующий вопрос по предмету **Proiectarea Sistemelor Informaționale** и сразу добавляет запись в `journal.xlsx`. При следующем запуске записи продолжаются с новой строки.

## Запуск

Для запуска из исходников нужен Go 1.26 или новее. В каталоге проекта:

```bash
go run .
```

По умолчанию журнал создаётся рядом с программой. Путь можно изменить:

```bash
go run . -file ./journal.xlsx
```

В терминале нажмите `ESC`, чтобы выйти. Пустые имя и фамилия не принимаются, пробелы по краям удаляются. После ввода студента программа сохраняет билет и ждёт следующего. Если Excel удерживает журнал открытым, программа предлагает закрыть файл и нажать Enter для повторной записи того же студента.

Банк вопросов в [questions.go](questions.go) составлен для **Proiectarea Sistemelor Informaționale**. Номер билета всегда соответствует одному и тому же вопросу; порядок вопросов нельзя менять после начала заполнения журнала. Вопросы написаны для этого проекта на основе тем [учебного материала UTM](https://repository.utm.md/handle/5014/15231), они не являются официальными экзаменационными билетами конкретного преподавателя.

Приложение работает в терминалах Windows, macOS и Linux. В обычном терминале `ESC` завершает работу без Enter.

### Windows без установки Go

1. Скачайте `ticket-generator-windows-amd64.zip` из [Releases](https://github.com/yr3kdvdv/exam-ticket-generator-go/releases).
2. Распакуйте архив в отдельную папку.
3. Откройте PowerShell в этой папке и выполните `.\ticket-generator.exe`.
4. Введите фамилию и имя студента. После сохранения записи файл `journal.xlsx` появится в этой же папке.
5. Чтобы посмотреть журнал в Excel, выполните `start .\journal.xlsx` или дважды щёлкните файл в Проводнике. Перед вводом следующего студента закройте журнал в Excel.

Архив рассчитан на 64-битную Windows. Для запуска готового `.exe` Go не нужен.

## Формат журнала

| A | B | C | D |
| --- | --- | --- | --- |
| Last name | First name | Номер билета | Дата и время |

Файл не добавляется в Git, поскольку содержит персональные данные студентов. Запись сначала создаётся во временном XLSX-файле и затем заменяет журнал. Это сохраняет ранее записанные строки при сбое во время обновления.

## Проверка

```bash
go test ./...
go vet ./...
```

Тесты проверяют сценарии обеих лабораторных работ: создание и дописывание Excel, повторный выбор студента, поиск группы, чтение Word, пропуск повреждённых билетов и отказ при Excel-блокировке. GitHub Actions запускает тесты при каждом push и pull request и собирает Windows GUI.
